# 隐私与数据范围

## 应用读取什么

- 本机 `127.0.0.1:9090` 的版本、配置端口和代理分组信息。
- Wi-Fi 的系统代理地址、端口和启用状态。
- 用户级 `com.mihomo.proxy` 服务状态。
- 名为 `Karing (system)` 的 VPN 连接状态；仅读取，不更改连接。

当前节点名称会显示在本机界面中，`--status-json` 也会输出该名称。

## 应用更改什么

只有用户点击启用或安全停止时，才更改属于控制范围的系统代理和 Mihomo 服务。启用操作会将 Wi-Fi 的三个代理指向 `127.0.0.1:7890`；停止操作只关闭同一地址和端口的代理。应用不解析或编辑订阅，不读取节点密码，不管理 Karing 连接。

## 不应公开的文件

不要将个人配置、订阅 URL、API secret、节点密码、UUID、环境变量文件、缓存数据库或运行日志放进仓库。Git 忽略规则只是一层保护，提交前仍应检查暂存内容。

构建缓存、应用包和 ZIP 位于被忽略的 `.build/` 与 `dist/`。本项目提供的界面截图来自虚构样例状态。

## 网络与遥测

应用没有遥测、远程日志或自动更新服务。状态查询只连接回环地址，节点面板入口只打开本地页面。Mihomo 内核自身的连接和订阅更新由用户已有的内核配置决定，不属于控制器的数据传输。
